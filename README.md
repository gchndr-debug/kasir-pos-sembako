# Sistem Kasir POS — Toko Sembako (`kasir-pos-sembako`)

Aplikasi **Point of Sale (POS)** berbasis web yang dirancang untuk mempermudah pencatatan transaksi kasir, manajemen inventaris stok barang, serta rekapitulasi riwayat penjualan pada usaha toko sembako dan ritel harian.

## Fitur Utama

* **Kasir / POS Interaktif:** Pencarian barang cepat berdasarkan nama atau kode SKU, serta filter kategori (*Bahan Pokok*, *Bumbu Dapur*, *Minuman & Cemilan*).
* **Keranjang Belanja & Kalkulasi Otomatis:** Menghitung subtotal item, potongan diskon (nominal Rp atau persentase), total pembayaran, hingga nominal kembalian secara *real-time*.
* **Manajemen Stok Barang:** Menambah produk baru, memantau sisa stok barang secara langsung, serta pengurangan stok otomatis saat transaksi selesai.
* **Cetak Struk & Riwayat Penjualan:** Mencatat nama kasir bertugas, nama pembeli, waktu transaksi, serta menghasilkan struk pembayaran siap cetak.

## Teknologi yang Digunakan

* **Frontend:** HTML5, CSS3 (Modern Responsive UI)
* **Logika & Penyimpanan Lokal:** Vanilla JavaScript & Browser LocalStorage
